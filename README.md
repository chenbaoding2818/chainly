### 一、背景
    这个项目是起源于本人所负责的一个商业项目，翻看了不少github基于golang的关于游戏项目能够开箱即用的构架甚少，所以决定加以修改开源出来，希望能帮助对游戏后端开发感兴趣的同学快速上手。
    本人水平有限，欢迎大家的加入，一起致力于打造一个开箱即用的游戏后端框架，共同进步。
### 二、项目架构介绍
网络通信的数据协议仅支持protobuf，原因很简单，就是流行，其他数据协议比如json因为各种原因逐渐被淘汰。
